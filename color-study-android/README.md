# 色スポイト(イラスト学習用)

スマホの写真・ダウンロードした画像から色をスポイトして、色メモとして残すアプリです。

## できること
- 「画像を開く」で画像を選ぶ(ギャラリーなどから「共有」でこのアプリに送ることもできます)
- 画像を指でなぞると、その場所の色を拾います(拡大鏡つき)。2本指で拡大・移動
- 「範囲」ボタンで、1ピクセル / 3×3 / 5×5 / 9×9 の平均色に切り替え
- 拾った色がクリスタ風のカラーサークル(色相のリング+彩度・明度の四角)に反映されます。サークルを触って色を変えることもできます
- HEX / RGB / HSV / HSL と、色の呼び名(例:「くすんだ青」)を表示
- メモを書いて「保存」(「肌」「影」などのボタンで入力を補助)
- 「メモ一覧」で、色の確認・コピー・メモ編集・削除・まとめて共有

## APKの作り方(GitHub Actions)
1. GitHubで新しいリポジトリを作る(例: color-study)。
2. このフォルダの中身(app, .github, build.gradle.kts, settings.gradle.kts, gradle.properties)をリポジトリ直下にアップロード。
3. 「Actions」→「Build APK」→「Run workflow」。
4. 完了後、Artifacts の color-study-apk(zip)の中の app-debug.apk をスマホに入れてインストール。

## 注意
- 色メモはアプリの中に保存されます。アンインストールすると消えるので、大事なメモは「まとめて共有」で残してください。
- 大きな画像(長辺3072px超)は、読み込み時に縮小します。
- 画像の色は、画面の表示ではなく画像データそのものの色を拾います(色の管理が特殊な画像では、見た目と少し違うことがあります)。
